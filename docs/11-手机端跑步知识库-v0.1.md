# 手机端跑步知识库 v0.1

> 状态（2026-11-19）：第一版可点击原型已完成并通过浏览器验收。内容与收藏都只在本次打开内有效，刷新恢复演示数据。
>
> 相关文档：[开跑记录与成长同步 v0.2（三通道）](10-开跑记录与成长同步-v0.1.md) · [双后台与平台总后台 v0.1](09-双后台与平台总后台-v0.1.md)

## 1. 这一版解决什么

原来的“经验库”只有首页一张静态卡，点“查看全文”不会进入可读内容。本版把它做成一条完整链路：

1. 首页经验库卡读取本周精选文章，点“查看全文”进入文章详情。
2. “去逛逛”进入跑步知识库列表。
3. 列表支持关键词搜索、全部/收藏切换、8 个主题筛选、空状态和重置。
4. 详情页包含正文、“今天就能做”清单、注意提示、收藏、关联阅读和返回列表。
5. “我的”页的经验库收藏显示实时篇数，并能直接进入知识库。

这仍然是**人工精选内容库**，不是 AI 问答，也没有接入大模型接口。AI 检索留到内容、审核和引用规范确定之后。

## 3. 页面与交互

### 3.1 首页入口

- 首页经验库卡显示精选文章的标题、摘要、阅读时长和难度。
- “去逛逛”和“查看全文”都进入知识库；“查看全文”直达 `/knowledge/breathing`。
- 首页不再维护第二份文章文案，标题和摘要直接读取 `FEATURED_ARTICLE`，避免两处不一致。

### 3.2 知识库列表 `/knowledge`

- 顶部显示“跑步知识库”、副标题和收藏总篇数。
- 搜索框匹配标题、摘要、分类和正文，大小写不敏感；输入后出现“清空”。
- “全部文章 / 我的收藏 N”切换；收藏模式只显示已收藏文章。
- 分类横向滑动：全部、入门、呼吸、配速、防伤、营养、恢复、比赛、身体。
- 默认状态显示深绿“本周精选”大卡；有关键词、收藏模式或非精选分类时隐藏精选卡，避免重复展示。
- 列表卡显示分类、收藏状态、标题、摘要、阅读时长、难度和“阅读”。
- 无结果时显示“没有找到相关文章”，并提供“清空搜索和筛选”；收藏为空时提示先收藏。
- 仅在默认状态显示“怎么用这个库”说明和“演示数据”提示。
- 可点击元素带 `testID`：`knowledge-search`、`knowledge-mode-all`、`knowledge-mode-saved`、`category-<主题>`、`knowledge-open-<文章id>`。

### 3.3 文章详情 `/knowledge/[id]`

- 顶部“返回知识库”、主题标签、“演示文章”标记。
- 标题、摘要、“N 分钟阅读 · 难度 · 面向青少年跑者”。
- 正文卡按段落展示；其后是“今天就能做”清单和粉色“注意”卡。
- 收藏按钮在“已收藏（点击取消）”和“收藏这篇”之间切换。
- “接着读”显示关联文章，可继续跳转；底部再次提供返回列表。
- 无效 id 有兜底页，不会因为直接改 URL 而白屏。

### 3.4 收藏联动

- `KnowledgeProvider` 在 `_layout.tsx` 中包住页面树，列表、详情和“我的”共用一份收藏状态。
- 演示初始收藏为 `breathing`、`easy-pace`、`knee`，所以首次进入显示 3 篇。
- “我的”页副标题显示“收藏了 N 篇训练与康复笔记”，点击进入 `/knowledge`。
- 收藏只在内存中；刷新页面恢复初始 3 篇。

文章结构：

```ts
type KnowledgeArticle = {
  id: string;
  category: KnowledgeCategory;
  title: string;
  summary: string;
  minutes: number;
  level: '入门' | '进阶';
  featured?: boolean;
  body: string[];
  checklist: string[];
  warning?: string;
  related: string[];
};
```

当前没有数据库表、接口或富文本编辑器；增加文章就是往 `KNOWLEDGE_ARTICLES` 里加一条记录。等接后端时，需要补作者、审核人、来源、发布时间、版本和发布状态。

## 5. 内容与安全边界

- 9 篇内容是为演示写的**项目稿**，没有署名作者、外部来源、医学审核或版本记录，不能当作正式科普发布。
- 每篇有“今天就能做”清单和“注意”红线条；涉及疼痛、胸闷、头晕、异常出血等情况，文案引导停止运动、告诉家长/老师并就医。
- 内容明确“非医疗建议”，不做诊断，不替代校医、教练或医生。
- 不收集伤病隐私，不做病友社区，不允许用户公开上传身体数据。
- 没有 AI 问答，不会把用户问题发给第三方模型；后续若做 AI 检索，只检索已审核文章，并显示引用来源。
- 正式上线前需要体育老师/教练/医生审稿，补作者与来源，建立内容更新和下架流程。

## 7. 已知边界

- 没有后台内容管理：不能投稿、审核、定时发布、下架或改版；文章只能改代码。
- 没有持久化：收藏刷新即恢复；换设备不同步。
- 搜索是本地字符串包含匹配，不处理同义词、拼音、错别字或相关度排序。
- 文章正文没有图片、视频、音频或可下载训练计划。
- 没有阅读进度、阅读历史、分享和评论。
- 没有无障碍专项测试；字号放大、读屏和键盘导航仍需验证。
- “我的”页其他入口还有只弹提示的占位项，本版只接通了跑团、成长、活动和知识库。

## 8. 下一步

1. 在平台总后台增加“知识库”工作区：文章列表、预览、审核、发布/下架，写审计日志。
2. 给文章补作者、审核人、来源、更新时间和“非医疗建议”固定声明。
3. 接 PocketBase 后，把文章和收藏落库；收藏按用户隔离。
4. 内容规模到 30 篇以上，再做相关推荐、阅读进度和搜索排序；AI 检索最后接，必须先有审核语料和引用规范。
5. 补移动端真机检查：字号放大、深色模式（若支持）、读屏、弱网和离线缓存。
