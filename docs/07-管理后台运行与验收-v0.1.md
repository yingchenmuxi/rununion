# 青跑团 · 管理后台运行与验收 v0.1

> 本文记录最早的社团后台。现在登录页已拆成“社团后台 + 平台总后台”两个工作区，完整说明、平台账号、页面路由和验收记录见 [双后台与平台总后台 v0.1](09-双后台与平台总后台-v0.1.md)。

## 1. 当前能跑什么

本地已经能打开一个可点击的社长后台：

- 地址：http://127.0.0.1:5173
- 演示账号：admin@qingrun.local
- 演示密码：Qingrun-Dev-2026
- 社团后台登录后包含 6 个页面：概览、成员、邀请码、公告、挑战、记录与导出。
- 同一登录页也可用平台账号 ops@qingrun.local / Qingrun-Dev-2026 进入平台总后台。

数据目前来自 `admin/src/data/mockRepository.ts`，不是真实数据库。刷新页面会回到示例状态；PocketBase 已经在 8091 端口运行，但后台还没有接它的表。

## 2. 本地启动

终端 1（PocketBase）：

```bat
cd /d E:\QPTapp
server\pocketbase.exe serve --http 127.0.0.1:8091 --dir server\pb_data --dev
```

终端 2（后台）：

```bat
cd /d E:\QPTapp\admin
npm run dev
```

打开 http://127.0.0.1:5173 。

## 3. 已验证

- `npm run typecheck`：通过。
- `npm run build`：通过，生成 `admin/dist`。
- 浏览器 1440×900：登录、概览、成员、邀请码、公告、挑战、记录页均正常渲染，无 console 错误。
- 交互：通过成员申请、生成邀请码、保存公告草稿、创建挑战、导出 CSV、退出登录，均已跑通。
