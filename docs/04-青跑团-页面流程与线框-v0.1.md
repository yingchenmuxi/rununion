# 青跑团 · 页面流程与线框 v0.1

- 日期：2026-11-16
- 依据：docs/03-青跑团-功能设计-v0.1.md
- 状态：设计稿，尚未开发
- 说明：这份文档只定页面结构、字段、按钮和验收标准；不做视觉稿，不改现有原型代码。

## 1. 已确认的选择

- 登录：**1A** 邀请码 + 用户名/密码，不强制手机号。
- V0.1 活动：**2A** 只做线上挑战/打卡，不做线下活动。
- 记录可见性：**3A** 默认社团可见；单条可设为私密；保留设置开关。
- 社团创建：**4A** 第一版只由平台管理员开通。
- 家长回执：**5C** V0.1 暂不收集；做线下活动/公开榜单前再补。

## 2. 信息架构

### 2.1 成员端（手机）

底部五个标签：

1. 首页
2. 跑团
3. 开跑
4. 成长
5. 我的

入团前页面（不显示底部标签）：

- 启动/登录
- 输入邀请码
- 创建账号
- 完善资料
- 等待审批

详情页：

- 公告详情
- 挑战详情
- 成员资料卡（底部弹层）
- 隐私设置
- 修改密码
- 删除账号

### 2.2 管理端（电脑 Web）

左侧菜单：

1. 概览
2. 成员
3. 邀请码
4. 跑步记录
5. 公告
6. 挑战
7. 数据导出
8. 审计日志
9. 社团设置

平台管理员另有：

- 社团管理
- 账号管理
- 平台审计

### 2.3 角色

- 跑者：加入社团、记录跑步、看自己的成长、看社团动态/公告/挑战。
- 社长（owner）：审批成员、发邀请码、发公告、建线上挑战、看社团汇总、导出数据；V0.1 只有 owner 一个管理员。
- 平台管理员：开通社团、指定社长、重置社长密码、停用社团、查看平台审计。
- 家长/老师：V0.1 不是 App 角色，不需要账号。

## 3. 关键流程

### 3.1 开通社团（平台管理员）

1. 平台管理员登录 Web 后台。
2. 新建社团：名称、城市/区、简介、常规训练地点。
3. 创建社长账号：用户名、昵称、临时密码。
4. 系统生成第一个邀请码。
5. 把后台地址、用户名、临时密码、邀请码线下交给社长。
6. 社长首次登录必须修改密码，然后可以生成新邀请码。

规则：

- V0.1 不开放社长自助建团。
- 一个社团只有一个 owner；可以有多名 admin。
- 平台管理员不查看成员私密记录。

### 3.2 加入社团（成员）

1. 打开 App，选择“我有邀请码”。
2. 输入邀请码，系统显示社团名称、城市、简介。
3. 创建账号：用户名、昵称、密码；勾选“我已满 14 岁”和用户协议/隐私政策。
4. 完善资料：年龄段、性别（可选）、城市/区、每周目标、默认可见性。
5. 提交加入申请，状态为“待审批”。
6. 社长在 Web 后台批准或拒绝。
7. 成员下次打开 App 看到结果；通过后进入首页。

规则：

- 用户名全局唯一；昵称不要求唯一。
- V0.1 一个账号只能加入一个社团。
- 邀请码可设置有效期和使用次数；过期/用完显示“邀请码已失效，请联系社长”。
- 被拒绝后显示“未通过，请联系社长”，不展示具体理由。
- 不收集手机号、邮箱、身份证、真实姓名、精确位置。

### 3.3 记录一次跑步

计时模式：

1. 进入“开跑”，默认计时模式。
2. 点“开始跑步”，计时开始；可暂停/继续。
3. 点“结束”，填写距离（必填）、感受、备注、可见性。
4. 保存。

手动模式：

1. 切换到“手动”。
2. 填写日期、距离、时长、感受、备注、可见性。
3. 保存。

规则：

- 距离 0.1–100 km；时长 1 分钟–12 小时。
- 日期不能是未来；最多补录 7 天前。
- 备注最多 100 字。
- 默认可见性取“我的”里的设置；单条可以改。
- 社团可见：出现在社团动态、计入社团汇总、可计入线上挑战。
- 仅自己可见：不出现在社团动态、不计入社团汇总、不计入挑战。
- 不采集 GPS；距离需要手动填写。
- 成员可以编辑/删除自己的记录；修改可见性后，社团动态同步更新。

### 3.4 线上挑战

1. 社长在 Web 后台创建挑战：标题、说明、开始/结束日期、目标类型（次数/距离）、目标值。
2. 成员在首页或跑团页看到挑战，点“参加”。
3. 活动期间，成员保存的“社团可见”跑步记录自动计入进度。
4. 成员在挑战详情看自己的进度；社团只显示“X 人参加、Y 人完成”，不排名。
5. 活动结束后挑战只读。

规则：

- 不做手动打卡，避免重复计入；进度由跑步记录自动计算。
- 私密记录不计入。
- 记录日期在挑战周期内才计入；挑战结束后补录不再计入。
- 不显示参与者速度排名、里程排名。
- 社长可以提前结束挑战，但不能删除已开始的挑战。

### 3.5 退出社团与删除账号

退出社团：

1. “我的” → “退出社团”。
2. 二次确认：退出后，你的社团可见记录会变为仅自己可见，并从社团动态/汇总中移除。
3. 退出后可以凭新邀请码重新加入；原记录保持私密，需要手动改回社团可见。

删除账号：

1. “我的” → “删除账号”。
2. 二次确认，输入用户名。
3. 账号立即停用，7 天内登录可撤销；7 天后删除/匿名化。
4. 社团汇总移除该成员数据；审计日志保留最小必要记录。

规则：

- 社长不能直接退出/删除；必须先由平台管理员转移 owner 或关闭社团。
- 被社长移出的成员，记录同样转为仅自己可见，并从社团动态/汇总移除。

## 4. 成员端页面规格

### 4.1 启动/登录

目的：让已有账号登录，或进入邀请码加入流程。

布局：

- 顶部：青跑团标识、口号“不追速度，只记录坚持”。
- 中部：两个主按钮“我有邀请码”“已有账号登录”。
- 底部：用户协议、隐私政策、版本号。

字段/按钮：

- 邀请码入口：进入 4.2。
- 登录：用户名、密码；“登录”按钮；“忘记密码”提示联系社长。
- 无手机号/邮箱登录。

状态：

- 账号不存在、密码错误、账号被停用、社团被停用。
- 已登录但资料未完善：直接进入 4.4。

### 4.2 输入邀请码

目的：确认邀请码有效，展示要加入的社团。

布局：

- 返回按钮。
- 标题“输入邀请码”。
- 邀请码输入框（6 位，自动大写）。
- 社团预览卡：名称、城市、简介、成员数。
- 主按钮“加入这个社团”。

状态：

- 邀请码不存在/过期/用完/社团停用：显示错误和“联系社长”。
- 已加入其他社团：显示“你已加入 X，V0.1 暂不支持同时加入多个社团”。

### 4.3 创建账号

目的：建立不依赖手机号的账号。

字段：

- 用户名：4–20 位字母/数字/下划线，全局唯一。
- 昵称：2–12 字，显示用，不要求真名。
- 密码：8–32 位；确认密码。
- 复选框：我已满 14 岁（必选）。
- 复选框：我已阅读并同意用户协议、隐私政策（必选）。

按钮：

- 创建并继续
- 返回

状态：

- 用户名被占用、密码太短、两次密码不一致、未勾选年龄/协议。
- 创建成功后进入 4.4；资料可稍后补，但年龄段和每周目标必须完成才能提交审批。

### 4.4 完善资料

目的：收集最少必要信息，建立成长档案。

字段：

- 头像：自动生成颜色 + 昵称首字；V0.1 不上传照片。
- 年龄段：14–15 / 16–17 / 18–20（必填）。
- 性别：男 / 女 / 不公开（可选）。
- 城市：默认社团城市，可修改（必填）。
- 区/县：可选。
- 每周目标：10 / 15 / 20 / 25 / 30 km，或自定义 1–100 km（必填）。
- 简介：最多 60 字（可选）。
- 默认记录可见性：社团可见 / 仅自己可见（默认社团可见）。
- 在成员列表展示本周跑量：开关，默认开。

按钮：

- 完成，提交审批
- 稍后完善（保存草稿，下次登录继续）

说明文案：

- “年龄段只用于分组，不展示完整生日。”
- “性别可不公开；V0.1 不做排名。”
- “不收集身份证、住址、精确位置。”

### 4.5 等待审批

目的：告诉成员申请已提交。

布局：

- 社团名称。
- 状态：“申请已提交，等待社长审批”。
- 提示：“审批通过后，下次打开 App 就能进入社团。”
- 按钮：“刷新状态”“返回登录”。

状态：

- 待审批、已通过（自动进首页）、已拒绝（显示联系社长）、社团停用。

### 4.6 首页

目的：一屏看到本周跑量、社团动态和当前挑战。

布局（从上到下）：

1. 顶部：社团名、头像。
2. 问候语：早上好/下午好，昵称。
3. 本周跑量卡：本周 km、目标 km、进度条、连续周数。
4. 快捷按钮：记录跑步 / 跑团 / 公告与挑战。
5. 当前挑战卡：标题、个人进度、剩余天数、参加/记录按钮。
6. 社团动态：最近 5 条社团可见记录。
7. 最新公告：置顶优先。
8. 底部标签栏。

字段/按钮：

- 本周跑量：来自自己的全部记录（含私密）。
- 社团动态：只显示社团可见记录；每条显示昵称、距离、时长、配速、感受、时间。
- 无评论、无点赞、无排名。
- “查看全部”进入跑团页动态。
- 下拉刷新。

空状态：

- 没有记录：“今天先跑一公里？” + 记录按钮。
- 没有挑战：“暂无挑战，等社长发布”。
- 没有公告：“暂无公告”。

### 4.7 跑团

目的：看社团成员、动态和公告。

布局：

1. 社团头部：名称、城市、成员数、本周总跑量、简介、常规训练地点。
2. 分段切换：动态 / 成员 / 公告。
3. 动态：社团可见记录列表，按时间倒序，加载更多。
4. 成员：头像、昵称、角色标签、加入时间、本周跑量（或“已隐藏”）。
5. 公告：置顶优先，显示标题、作者、日期。
6. 社长/管理员按钮：邀请成员、管理后台。
7. 普通成员按钮：退出社团。

规则：

- 成员列表不按速度/跑量排序；默认按加入时间。
- 不显示手机号、真实姓名、精确位置。
- 点成员打开资料卡：昵称、简介、角色、本周跑量（如允许）；没有私信按钮。
- 私密记录不出现在动态，也不计入社团总跑量。

### 4.8 开跑

目的：用最少步骤记录一次跑步。

布局：

1. 标题“开跑”。
2. 模式切换：计时 / 手动。
3. 计时模式：大号计时器；开始/暂停/结束按钮。
4. 手动模式：日期、距离、时长。
5. 共同字段：感受（1–5）、备注、可见性。
6. 保存按钮。
7. 静态热身提示（可选展开，不存储）。

字段/按钮：

- 计时：开始、暂停、继续、结束。
- 距离：数字输入，单位 km，保留 1 位小数。
- 时长：计时自动带入；手动输入时/分/秒。
- 感受：很好 / 好 / 一般 / 累 / 很难受。
- 备注：最多 100 字。
- 可见性：社团可见 / 仅自己可见；默认取设置。
- 保存记录。

状态：

- 未开始、进行中、已暂停、已结束待填写。
- 保存成功：显示本次距离/时长/配速；“已同步到社团”或“仅自己可见”。
- 校验失败：提示具体字段，不丢失已填内容。
- 保存失败：保留草稿，提示重试。

### 4.9 成长

目的：让成员看到自己的坚持，不做排名。

布局：

1. 本月成长卡：本月 km、连续周数、跑步次数。
2. 本周目标进度。
3. 最近 4 周跑量柱状图。
4. 最近记录列表：日期、距离、时长、可见性标识。
5. “导出我的数据”按钮。

规则：

- 只显示自己的数据，包括私密记录。
- 不做个人速度榜、社团排名。
- 个人最好成绩 V0.2 再设计；V0.1 不录入。
- 空状态引导记录第一次跑步。

### 4.10 我的

目的：管理资料、隐私和账号。

布局：

1. 资料卡：头像、昵称、年龄段、社团、角色；编辑按钮。
2. 隐私设置：
   - 默认记录可见性：社团可见 / 仅自己可见。
   - 在成员列表展示本周跑量：开/关。
3. 账号安全：修改密码、退出登录。
4. 社团：退出社团。
5. 关于：用户协议、隐私政策、版本号。
6. 危险区：删除账号。

规则：

- 修改默认可见性只影响之后的新记录，不改变历史记录。
- 关闭“展示本周跑量”后，成员列表显示“已隐藏”；社团汇总仍统计其社团可见记录，但不显示个人数字。
- 社长/管理员显示“管理后台”入口。
- 退出社团/删除账号按 3.5 的规则。

### 4.11 公告详情

布局：

- 返回按钮。
- 标题、作者、日期。
- 正文（纯文本，支持换行）。
- 置顶标识。

规则：

- 成员只读；无评论。
- 公告由社长/管理员在 Web 后台创建、编辑、删除、置顶。

### 4.12 挑战详情

布局：

1. 标题、状态（进行中/已结束）。
2. 日期范围、目标类型和目标值。
3. 我的进度：已完成 / 目标；进度条。
4. 社团完成情况：X 人参加、Y 人完成（不排名）。
5. 规则说明：仅社团可见记录计入；私密记录不计入；结束后补录不计入。
6. 按钮：参加 / 退出 / 记录跑步。

规则：

- 进度自动计算，不做手动打卡。
- 不显示参与者速度/里程排序。
- 结束后只读；社长可提前结束。

## 5. 管理端页面规格

### 5.1 登录与角色

- 用户名 + 密码登录。
- 社团管理员进入自己社团；平台管理员进入平台视图。
- 首次登录/被重置密码后必须改密码。
- 忘记密码：社团管理员由平台管理员重置；成员由社团管理员重置。

### 5.2 概览

卡片：

- 成员总数、待审批数、本周社团总跑量、进行中挑战数。
- 快捷入口：审批成员、生成邀请码、发公告、建挑战。

列表：

- 最近加入成员（5 人）。
- 最近公告（3 条）。

### 5.3 成员

表格列：

- 昵称、用户名、年龄段、性别、状态、加入时间、本周跑量（如允许，否则“已隐藏”）。

筛选：

- 状态：待审批 / 正常 / 已移出。
- 搜索：昵称/用户名。

操作：

- 批准、拒绝（待审批）。
- 移出社团（二次确认）。
- 重置密码（生成临时密码，只显示一次，写审计）。
- 导出当前筛选结果 CSV。

限制：

- 不能查看私密记录。
- 不能修改成员资料/跑步记录。
- 不能把成员设为管理员；V0.1 只有 owner 一个管理员，变更由平台管理员处理。

### 5.4 邀请码

列表：

- 邀请码、创建人、创建时间、有效期、已用/上限、状态。

操作：

- 新建：有效期（1/7/30 天）、使用上限（默认 50）。
- 复制、停用。
- 邀请码 6 位大写字母/数字。

### 5.5 跑步记录

表格列：

- 成员昵称、日期、距离、时长、配速、感受、可见性。

筛选：

- 日期范围、成员。

操作：

- 查看、导出 CSV；不能编辑/删除。
- 只显示社团可见记录；私密记录不出现。

### 5.6 公告

列表：标题、作者、置顶、发布时间、状态。

操作：

- 新建/编辑/删除/置顶。
- 正文纯文本，最多 2000 字。
- 删除需二次确认。

### 5.7 挑战

列表：标题、日期、目标、参加人数、完成人数、状态。

新建字段：

- 标题、说明、开始日期、结束日期、目标类型（次数/距离）、目标值。

操作：

- 创建、编辑（未开始）、提前结束、查看参加人数/完成人数。
- 不提供排名表；参与者列表按加入时间，不按成绩排序。

### 5.8 数据导出

- 成员 CSV：昵称、用户名、年龄段、性别、状态、加入时间、本周跑量（仅允许展示的）。
- 跑步记录 CSV：成员昵称、日期、距离、时长、配速、感受、可见性。
- 日期范围选择。
- 不含私密记录；导出动作写审计日志。

### 5.9 社团设置

- 社团名称、城市/区、简介、常规训练地点。
- 保存后成员端同步。
- 社长不能修改自己的 owner 身份；需要平台管理员操作。

### 5.10 审计日志

记录：

- 审批/拒绝成员、移出成员、重置密码、生成/停用邀请码、发/删公告、建/结束挑战、导出数据。

字段：

- 时间、操作人、动作、目标、结果。

权限：

- 社团管理员看本社团日志；平台管理员看平台日志。

### 5.11 平台管理员

- 新建社团。
- 创建/重置社长账号。
- 停用/恢复社团。
- 查看平台审计。
- 不进入社团私密记录；不代替社长做日常审批。

## 7. V0.1 验收清单

### 7.1 开通与账号

- [ ] 平台管理员能创建社团，并创建 owner 账号。
- [ ] owner 首次登录必须改密码。
- [ ] owner 能生成、复制、停用邀请码。
- [ ] 邀请码过期/用完时，成员看到明确错误。
- [ ] 成员能用邀请码创建账号（用户名+密码），不需要手机号。
- [ ] 用户名重复、密码太短、未勾选 14+/协议时有提示。
- [ ] 成员提交后为待审批；owner 批准后能进入首页；拒绝后有提示。
- [ ] 忘记密码时，owner 能重置成员密码；平台管理员能重置 owner 密码。

### 7.2 资料与隐私

- [ ] 成员能填写年龄段、性别（可不公开）、城市、每周目标、默认可见性。
- [ ] 头像自动生成，不需要上传照片。
- [ ] “我的”里能切换默认可见性；只影响新记录。
- [ ] “展示本周跑量”关闭后，成员列表显示“已隐藏”。
- [ ] 任何页面都不显示手机号、真实姓名、精确位置。
- [ ] 成员能导出自己的数据。

### 7.3 跑步记录

- [ ] 计时模式能开始/暂停/继续/结束，结束后能填距离并保存。
- [ ] 手动模式能填日期、距离、时长并保存。
- [ ] 距离/时长/日期/备注校验生效。
- [ ] 保存后，个人成长数据更新。
- [ ] 社团可见记录出现在社团动态，并计入社团汇总。
- [ ] 私密记录不出现在社团动态，不计入社团汇总/挑战。
- [ ] 成员能编辑/删除自己的记录；改成私密后从社团动态移除。

### 7.4 社团与挑战

- [ ] 跑团页能切换动态/成员/公告。
- [ ] 成员列表按加入时间展示，不按跑量排序。
- [ ] 成员资料卡不显示联系方式和私信按钮。
- [ ] owner 能发公告、置顶、删除。
- [ ] 成员能看公告详情。
- [ ] owner 能创建线上挑战（次数/距离）。
- [ ] 成员能参加/退出挑战。
- [ ] 社团可见记录自动计入挑战；私密记录不计入。
- [ ] 挑战页只显示个人进度和参加/完成人数，不显示排名。
- [ ] 挑战结束后只读，补录不再计入。

### 7.5 管理后台

- [ ] 概览显示成员数、待审批数、本周总跑量、进行中挑战数。
- [ ] 成员页能筛选、批准、拒绝、移出、重置密码、导出。
- [ ] 邀请码页能新建/复制/停用。
- [ ] 记录页只显示社团可见记录，不能编辑/删除。
- [ ] 公告页能新建/编辑/删除/置顶。
- [ ] 挑战页能创建/编辑未开始/提前结束。
- [ ] 导出 CSV 不含私密记录，导出动作写审计。
- [ ] 审计日志记录审批、移出、重置密码、邀请码、公告、挑战、导出。
- [ ] 平台管理员能建团、重置 owner、停用社团，不能看私密记录。

### 7.6 退出与删除

- [ ] 退出社团有二次确认；社团可见记录转为私密并从社团移除。
- [ ] 被移出的成员同样处理。
- [ ] 删除账号立即停用，7 天内可撤销，之后删除/匿名化。
- [ ] 社长不能直接退出/删除；需要平台管理员转移/关闭。

### 7.7 体验与安全

- [ ] 390 px 宽度下成员端无横向溢出，底部五标签都可点。
- [ ] 管理后台在 1280 px 宽度下可用。
- [ ] 所有列表有加载中、空状态、失败重试。
- [ ] 表单错误提示具体到字段，不丢已填内容。
- [ ] 按钮点击区域不小于 44 px。
- [ ] 密码加密存储；登录有频率限制；接口校验角色权限。
- [ ] 私密记录在 API、页面、导出中都不可见（用两个账号测试）。
- [ ] 本地备份可用；上线前补 HTTPS、隐私政策、备案。

### 7.8 测试数据

- [ ] 1 个平台管理员、1 个 owner、10 个成员（含待审批/已拒绝/已移出）。
- [ ] 30 条跑步记录（社团可见/私密混合）。
- [ ] 2 条公告、1 个进行中挑战、1 个已结束挑战。
- [ ] 用两个账号互相验证：看不到对方私密记录。

## 9. 已确认的默认规则（2026-11-17）

以下 10 条已于 2026-11-17 确认，作为 V0.1 默认规则；后续要改，先记录变更原因和影响：

1. 一个账号 V0.1 只能加入一个社团。
2. 用户名全局唯一；昵称可重复。
3. 跑步记录最多补录 7 天；不能填未来日期。
4. 私密记录完全不计入社团汇总和挑战。
5. 退出/被移出社团后，历史社团可见记录转为私密。
6. 删除账号有 7 天冷静期。
7. 社长不能直接退出；需要平台管理员处理。
8. 挑战由社团可见记录自动累计，不做手动打卡。
9. V0.1 不做成员角色转移；只有 owner 一个管理员，平台管理员可指定。
10. 管理后台只做电脑 Web，不做手机管理端。
